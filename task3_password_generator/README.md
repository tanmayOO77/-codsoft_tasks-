# Task 3 — Password Generator

> **CodSoft Python Programming Internship**

## 📋 Task Description

A password generator that creates strong, random passwords.  
Users can specify the length and complexity of the password.

## ✨ Features

- 🔐 Generate random passwords of any length (4–128)
- 🔠 Toggle **uppercase** letters
- 🔢 Toggle **digits**
- 🔣 Toggle **special characters**
- 💪 **Password strength** indicator (Weak / Medium / Strong)
- 🔄 Generate multiple passwords in a loop
- ✅ Input validation

## 🚀 How to Run

```bash
python password_generator.py
```
