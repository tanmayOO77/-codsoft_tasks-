# Task 1 — To-Do List Manager

> **CodSoft Python Programming Internship**

## 📋 Task Description

Design a To-Do List application that allows users to create, manage, and track their tasks.

## ✨ Features

- ➕ **Add** new tasks
- 👁️ **View** all tasks with completion status
- ✅ **Mark** tasks as done
- 🗑️ **Delete** tasks
- 💾 **Persistent storage** using JSON file
- 📊 **Progress tracking** (completed/total)
- ✅ Input validation

## 🚀 How to Run

```bash
python todo_list.py
```
